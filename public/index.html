SpeedFace-V5L Network & Real-Time Push Setup

Follow these quick steps on the physical SpeedFace machine to enable real-time facial recognition push

💡
Your Computer's Local IP Address:
Loading IP...

Use this IP address when configuring the Cloud Server / ADMS menu on your SpeedFace terminal.

1

Verify Network Connection

On your SpeedFace-V5L terminal screen:

  • Tap the screen and enter Menu (Admin authentication if locked).
  • Go to Comm. → Ethernet (or Wireless Network).
  • Ensure IP Address is set to 192.168.10.15, Subnet Mask 255.255.255.0, Gateway 192.168.10.1.
2

Configure Cloud Server / ADMS (Real-time Push)

To enable real-time instant punch uploads whenever someone looks at the camera:

  • In Menu, navigate to Comm. → Cloud Server Setting (or ADMS / Web Server).
  • Server Mode: ADMS / Cloud Server
  • Enable Domain Name: OFF (Set to OFF to enter an IP directly)
  • Server Address: Enter your PC's IP (192.168.10.57)
  • Server Port: 8088
  • Enable Proxy Server: OFF
  • Tap OK / Save.
3

Enjoy Zero-Touch Automatic Attendance!

The device will instantly connect to this application. Whenever an employee scans their face or palm:

  • A live sound/visual alert will appear on the Dashboard.
  • The record is saved permanently in your SQLite database.
  • You can filter and export reports to Excel (.xlsx) or CSV anytime!
